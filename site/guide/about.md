## Numbers and labels

- A worked number in a primer is either computed by code in the repository (the page names the function) or marked
  `(verify)` with a date. Product names, versions, prices and availability change month to month; most primers end
  with a list of what to re-check.
- Output that does not come from real hardware is labelled: simulator output says "simulated"; bundled tool output
  says "sample output in the documented format (illustrative)".
- An unmarked number you cannot trace to code is a mistake worth reporting.

## Reporting an error

Open an issue on [GitHub](https://github.com/aniryou/full-stack-agentic-engineer/issues) with the page, the claim,
and what you think is right, ideally with a source or a command that shows it.

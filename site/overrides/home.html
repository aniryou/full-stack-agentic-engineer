Full-stack agentic engineer

A learning repository for the LLM serving stack, from the GPU and its fabric to the agent application, organised as eight layers and, within each layer, by topic. Each topic has a primer, a small from-scratch implementation and a fuller lab, with notebooks for both. This site is a readable copy of the repository; code files open on GitHub.

How to use it

  1. Pick a layer from the stack, or follow the learning path, which orders the topics and estimates the hours.
  2. Read the topic's primer first, section by section as the notebooks ask for it.
  3. Run the core notebooks. They need no GPU: a laptop or a free Colab CPU session is enough. Each exercise is followed by a check cell.
  4. Go on to the lab when you have a GPU or a cloud project. Every lab notebook also has an offline path.
  5. To redo an exercise, git restore <notebook> returns it to blank; on Colab, reopen it from its badge.

Run tiers

Every notebook says which tier it needs. Prices are approximate (verify); see Compute.

T0
A laptop, Colab CPU or CI. Free.
T1
One small GPU: free on Colab or Kaggle, or about $0.3–0.7 an hour rented.
T2
A multi-GPU box: free over PCIe on Kaggle, or about $1–6 for an hour on two NVLink GPUs.
T3
Google Cloud through Terraform. Pay per use; defaults to Spot L4 GPUs that scale to zero.

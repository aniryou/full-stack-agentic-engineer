# deploy/local — the stack in Docker Compose (T0/T1, CPU only)

Three vLLM-shaped backends, the lab router in front of them, and Prometheus scraping everything.

| Profile | Backends | Needs |
|---|---|---|
| `sim` (default) | 3 × `ghcr.io/llm-d/llm-d-inference-sim:v0.11.2` (verify tag) | Docker, pull access to ghcr.io |
| `fake` | 3 × the bundled `igwlab.fakebackend` (built from this lab) | Docker only |

Both run the same latency model (TTFT = 2 ms + 50 µs × uncached prompt tokens, 4 ms per output token,
8 batch slots, 2,048 × 16-token KV blocks with prefix caching): the simulator flags are generated by
`EngineProfile().sim_args()` and `tests/test_manifests.py` keeps them in sync.

```bash
./up.sh                    # PROFILE=fake ./up.sh for the bundled backend; DRY_RUN=1 prints the steps
./smoke.sh                 # 3 identical long-prefix requests: all land on the same backend
open http://localhost:9090 # Prometheus: try  sum by (endpoint) (igw_request_total)
./down.sh                  # remove containers, network and the locally built image
```

The router listens on `http://localhost:9000` (`/v1/chat/completions`, `/metrics`, `/debug/state`)
with the `default-weighted` preset and two InferenceObjectives (`premium=100`, `batch=-10`, chosen per
request with the header `x-llm-d-inference-objective`). Notebook 04 benchmarks it if it is running.

**Cost:** free (local CPU). **Cleanup:** `./down.sh`.

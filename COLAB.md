# Running notebooks in Google Colab

This repo is **private**, so two one-time setups let every notebook run in Colab. The per-notebook
**"Open in Colab"** links live in each layer's own `README.md` (you'll see them when you open a layer),
not here.

## One-time setup
1. **Open notebooks from GitHub:** in Colab, *File -> Open notebook -> GitHub*, tick *Include private
   repos*, and authorize Colab's GitHub access.
2. **Let the first cell clone the repo:** add a GitHub token (repo scope) to Colab **Secrets** (the key
   icon in the left sidebar) named `GH_TOKEN`. Every notebook's first cell uses it to clone this repo and
   install that lab's dependencies.

## Redo an exercise
`git restore <notebook>` returns it to the committed blank; for percent-source labs, re-run the lab's
`python3 tools/build_notebooks.py`.

_Per-layer notebook links are generated by `tools/gen_colab_index.py`._

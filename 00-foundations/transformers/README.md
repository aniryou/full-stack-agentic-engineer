# Transformer lessons

Three short, runnable Python files that build the core of a Transformer from nothing, plus a fill-in-the-blank
practice notebook. Companion to `docs/transformer-primer.md`.

The core concept, in one line: **attention moves information between positions; the MLP processes it within a
position; a Transformer is that pair, stacked.** Every file below exists to make one part of that sentence visible
in printed numbers.

**Time and tier:** ~5 h with the primer; module 00.1 in [`CURRICULUM.md`](../../CURRICULUM.md). T0 = a laptop or Colab CPU, free: lessons 1–2 and the practice notebook need only numpy; lesson 3 and the two notebooks in `notebooks/` need CPU PyTorch (T0 + torch; Colab has it). No GPU, no key.

## Setup

```bash
pip install -r requirements.txt      # numpy for lessons 1-2 and the notebook; torch (CPU is fine) for lesson 3
```

## Lessons — read top to bottom, then run

| File | What it builds | What to look for in the output |
|---|---|---|
| `lessons/01_attention.py` | Scaled dot-product attention in ~15 lines of numpy | Weights always sum to 1 (it's an average, not a selection). Without the `1/sqrt(d_k)` the softmax saturates. Shuffling the tokens shuffles the output identically: attention has no idea about order until you add positions. The causal mask puts exact zeros above the diagonal. |
| `lessons/02_block.py` | A full block: multi-head attention + MLP + residuals + norm | Same shape in, same shape out. `block(x) == x + attention_update + mlp_update`. Nudge token 2: the MLP changes only row 2; causal attention changes rows 2–5; unmasked attention changes everything. Parameter count from `12·d²` reproduces GPT-2 small's 124M. |
| `lessons/03_tiny_gpt.py` | A 26k-parameter GPT trained on a copy task, ~15 s on CPU | Loss starts at `ln(vocab)`. The unpredictable half of each sequence never improves; the copyable half drops to zero. Greedy decoding reproduces the prompt. One head puts ~80% of its weight on "the token six positions back" — a rule nobody wrote. |

Primer sections: lesson 1 ↔ §2, lesson 2 ↔ §3 and §8, lesson 3 ↔ §5–7.

## Practice

`practice/attention_practice.ipynb` has eight exercises with `...` blanks: softmax → attention → causal mask →
heads → multi-head attention → the block → parameter counting → an order-blindness experiment. Each has a check
cell that prints ✅ when it passes and says what's wrong when it doesn't. `practice/attention_solutions.ipynb` is
the filled-in version; both are generated by `practice/build_notebooks.py`.

Open either in Jupyter, VS Code, or upload to Colab.

## Where to go next

- Vary the copy length in lesson 3 (`K` random per example). A fixed offset can be solved by a positional lookup;
  a variable one needs an *induction head* — two heads working together. See if it still trains.
- Add a KV cache to `generate()` in lesson 3 and confirm the output is identical.
- Swap `nn.LayerNorm` for RMSNorm, the position table for RoPE, and the MLP for SwiGLU. Those three edits turn
  the lesson-3 model into a Llama-style one.
- Karpathy's `nanoGPT` is the same architecture trained on real text; after these three files it should read as
